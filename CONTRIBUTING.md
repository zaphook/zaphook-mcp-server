# Contributing

This repository holds the documentation and client examples of the hosted ZapHook MCP Server. Fixes and additions are welcome, especially:

- setup instructions for an MCP client that is not covered yet;
- corrections when a client changes its settings screens or config format;
- clearer troubleshooting answers and example prompts;
- translations.

## How to contribute

1. Fork the repository and create a branch, for example `docs/windsurf-setup`.
2. Make the change. Keep the English and Portuguese READMEs in sync when you change shared content.
3. Test any configuration you add against the real server with your own API key.
4. Open a pull request describing the client and version you tested.

## Rules

- **Never include a real API key**, phone number, message content or screenshot that shows them. Use `YOUR_API_KEY` and `5511999998888`.
- Bugs or feature requests about the server's behavior go to [Issues](https://github.com/zaphook/zaphook-mcp-server/issues).
- Security problems go through [SECURITY.md](SECURITY.md), not issues or pull requests.
