# Changelog

Changes to the hosted ZapHook MCP Server and this documentation.

## 1.0.0

First public release. 31 tools:

- **Inbox (read-only):** list conversations, get a conversation, list its messages, with the 24-hour window status.
- **Messages:** text, templates, image, video, audio, document, sticker, location, location request, contact cards, buttons, lists, reactions, mark as read and typing indicator.
- **Channels and templates:** list, get, live number health, templates, create, update and delete standard channels.
- **Destinations:** list, create, update and delete webhooks.
- **Events:** list and inspect received and delivered events, for standard and coexistence channels.

Works with Claude (claude.ai, Desktop, Code), Cursor, VS Code, Kiro and any Streamable HTTP client with custom headers.
